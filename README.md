# Shared Joys

A RimWorld mod that lets colonists invite each other to hang out, relax, or sweep a lover off their
feet for a romantic break. Created by Blues, maintained with Blues' agreement.

## Features

- **Group recreation:** select a colonist and invite friends to share a recreation spot.
- **Sweep off feet:** physically carry a lover to chill.
- **Automated scheduling:** configure hours where colonists organise group hangouts on their own.
- **Places beyond the obvious:** art pieces, graves and meditation foci count as spots.
- **Activities with no place:** walks, skygazing, swimming, reading, prayer and more, from "Invite
  ... to an activity".
- **Board games on the ground** when no chair is free.
- **Customizable:** friendship thresholds, proximity limits, recreation duration, room pickiness,
  allowed areas.

See [CHANGELOG.md](CHANGELOG.md) for what changed.

## Build

```
dotnet build Source/BluesSharedJoys.csproj -c Release
```

The assembly is written to `Mod/Assemblies/`. `Mod/` is the folder RimWorld loads.
